#  DEEP LEARNING 

##  Giới thiệu
Repository này tổng hợp các kiến thức và bài thực hành về **Deep Learning** trong quá trình học tập và nghiên cứu.  
Bao gồm các mô hình từ cơ bản đến nâng cao như ANN, CNN, RNN, LSTM cùng với các thư viện phổ biến trong Python.

---

##  Cấu trúc thư mục

- `ANN/` – Mạng nơ-ron nhân tạo cơ bản  
- `CNN/` – Mạng tích chập (xử lý ảnh)  
- `RNN/` – Mạng hồi tiếp  
- `LSTM/` – Mô hình LSTM (chuỗi thời gian, NLP)  
- `Pytorch/` – Các ví dụ sử dụng PyTorch  
- `NUMPY, PANDAS, Matplotlib/` – Xử lý dữ liệu & trực quan hóa  
- `pandas/` – Các bài tập liên quan đến dữ liệu  
- `lab5/` – là các mô hình CNN có độ chính xác trên 90% được viết thành web

##  Nội dung chính

###  Machine Learning & Deep Learning cơ bản
- Xây dựng mô hình ANN
- Huấn luyện và đánh giá mô hình

###  Computer Vision
- CNN cho phân loại ảnh
- Xử lý ảnh bằng OpenCV

###  Sequence Models
- RNN, LSTM cho:
  - Dự đoán chuỗi thời gian
  - Xử lý ngôn ngữ tự nhiên (NLP)

###  Data Processing
- Sử dụng:
  - NumPy
  - Pandas
  - Matplotlib
